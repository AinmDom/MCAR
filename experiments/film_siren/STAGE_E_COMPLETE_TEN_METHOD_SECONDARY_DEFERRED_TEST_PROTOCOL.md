## 1. Scope and evidence boundary

This protocol completes the registered ten-method horizontal comparison on the 44
SONICOM test subjects. The method order is fixed to:

1. SH only (`SHOnly`);
2. SUpDEq SH (`SUpDEqSH`);
3. SUpDEq NN (`SUpDEqNN`);
4. SUpDEq Barycentric (`SUpDEqBary`);
5. MCA (`MCA`);
6. MCAR v3.5.1 (`MCARv351`);
7. FSP-AE (`FSPAE`);
8. RANF (`RANF`);
9. Hybrid E190 (`HYBRID`); and
10. Bounded E25 (`BOUNDED`).

The four primary engineering-test endpoints already exist for all ten methods in
`results/sonicom_film_siren_spectral_cnn_final_e190_frozen_test_ten_method/metric_long.csv`.
Those 1,760 subject-level rows are reused byte-for-byte as the primary source; model
inference and primary endpoint evaluation are not repeated.

The present run adds the 16 previously validation-only endpoints below. Because the
SONICOM test split has already been consumed by earlier locked primary evaluations,
these new endpoints are prospectively frozen only with respect to their own computation.
They are **post-lock supplementary test characterization**, not an untouched independent
confirmation set, and cannot be used to retrain, tune, select, reweight, or promote a
model.

## 3. Data and reconstruction

- Split: the frozen 44-subject SONICOM `test` split.
- Directions: 793 total, Q26 observations excluded, 767 interpolation directions.
- Horizontal subset: 72 interpolation directions.
- Selected frequency bins: 463, 86.1328125--19982.8125 Hz.
- Subject is the independent statistical unit.
- Every spatial subset renormalizes its solid-angle weights.

Five traditional methods are reconstructed once by the existing SUpDEq/MCA MATLAB
implementation and exported to a standardized HDF5 representation. The same exporter
also standardizes the already frozen MCAR v3.5.1, FSP-AE, and RANF test predictions.
Hybrid E190 and Bounded E25 reuse their completed-registry residual predictions; their
HRIRs are generated by the already qualified strict reconstruction with subject-specific
MCA phase and outside-bin complex values. No checkpoint is loaded for inference.

The standardized eight-method export must reproduce the existing four primary
subject-level test metrics for the shared methods to a maximum absolute tolerance of
`1e-9 dB` before supplementary results are accepted.

## 4. Statistics and outputs

- Retain all 44 subjects; no exclusions, outlier removal, or result-dependent retries.
- For every method/endpoint report mean, sample SD, and a 95% percentile interval from
  10,000 subject bootstrap resamples.
- Bootstrap generator: NumPy PCG64; base seed `20260902`, with deterministic
  method/endpoint-derived seeds recorded in the output.
- For every endpoint, compute Bounded-minus-each-other-method subject-paired summaries:
  mean difference, 95% percentile interval, median, P90, P95, worst-decile mean,
  maximum degradation/subject, and win/tie/loss counts.
- No multiplicity-adjusted confirmatory family, composite score, or single cross-metric
  rank is defined.

Frozen output roots:

- standardized inputs: `artifacts/reconstruction/sonicom_complete_ten_method_secondary_test_inputs_v1/`;
- raw supplementary results: `results/sonicom_complete_ten_method_secondary_deferred_test_v1/`;

## 5. Result-blind freeze sequence

Before parsing any new test endpoint value:

1. commit this protocol, the dedicated evaluator, tests, manifest generator, and the
   minimal exporter split-metadata correction;
2. from that clean commit, generate a hash-locked manifest covering the 44-subject
   split, reference/source inventory, five completed prediction inventories, primary
   source CSV, code, dependencies, runtime, exact commands, and output roots;
3. commit the manifest and reconfirm a clean tracked tree;
4. run the standardized export once, verify 8 methods × 44 subjects, finite arrays,
   split labels, and primary reproduction; and
5. run the unified supplementary evaluator once.

Only a failure proven to occur before any endpoint is aggregated may be repaired. Any
repair requires preserving the failed output, committing the minimal correction, and
generating a new manifest identity before retry. Completed Bounded and Hybrid registries
must never be reset or overwritten.

- horizontal interpolation count is 72 and ERB-band count is 35;

- no output directory is overwritten and no model inference is performed; and
- the run records `test_subject_count_read=44`, while preserving the historical
