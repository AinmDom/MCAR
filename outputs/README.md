# 实验输出与训练数据

此目录用于保存大型实验特征、缓存、中间结果、模型权重和评估数据。它们不提交到
Git，以避免仓库包含机器相关或体积过大的文件。

项目应有 `mca_demo_ku100_N3/mca_demo_features.mat`（约 281 MB），其中保存
MCA demo 的训练特征。该文件不是可下载数据包，且当前仓库尚未包含其专用导出脚
本；跨电脑需要从原始实验重新导出，或向项目维护者获取相同实验产物。取得后应保
持原有相对路径。

所有新输出都应在 `docs/EXPERIMENT_LOG.md` 记录生成命令、数据来源、参数和本
机路径。

该 README 是此目录中唯一应提交到本项目 Git 仓库的文件。
