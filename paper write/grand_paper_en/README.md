# CSMT 2026 English LaTeX package

Main manuscript: `main.tex`  
Supplementary material: `supplementary_paired_statistics.tex`

This package follows the supplied CSMT English LaTeX template: A4 paper, the template margins, Times New Roman as the primary Latin font, English-only title/abstract/keywords/captions, no page numbers, and the supplied GB/T 7714-2015 numerical bibliography style.

Compile with XeLaTeX and BibTeX (or `latexmk -xelatex`) from this directory. No PDF is committed here; generated LaTeX files and `main.pdf` are ignored. The author name remains the source-paper placeholder `Young` and should be replaced or anonymized before submission as required by the review stage.
