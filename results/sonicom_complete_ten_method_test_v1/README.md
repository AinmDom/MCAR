# Complete ten-method test comparison

This package consolidates the four frozen primary engineering-test endpoints and the sixteen post-lock supplementary test endpoints for all ten registered methods and 44 subjects.

`paper_complete_test_wide.csv` is the one-row-per-endpoint paper table; `aggregate_metrics.csv` adds subject-bootstrap intervals and ranks; `per_subject_metrics.csv` preserves all paired values; `paired_vs_bounded.csv` reports Bounded-minus-baseline paired effects; `method_registry.csv` is the complete locked horizontal-comparison method list.

The supplementary test results are characterization only and were not used for tuning or model selection.
